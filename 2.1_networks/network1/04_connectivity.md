### 4.2 Describe the Results
- Were all PCs able to ping each other?  
- Which pings were successful?  
- Which ones failed and why?
All PCs were able to communicate with each other successfully using the ping command. The ping tests confirmed that the computers were connected correctly to the network and had valid IP addresses. The pings between PC0, PC1, PC2, PC3, and PC4 were successful. Each computer received replies from the destination PC, showing that the network connection was working properly. The ping statistics showed that packets were sent and received successfully with 0% packet loss. No ping tests failed during the connectivity testing. However, ping tests may fail if the IP address is incorrect, the network cable is disconnected, the devices are not connected properly, or the IP configuration is incorrect. Overall, the results demonstrated that all PCs could communicate successfully within the local network.
