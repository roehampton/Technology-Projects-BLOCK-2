### 4.2 Describe the Results

**Were all PCs able to ping each other?**

Yes, all five configured PCs were able to ping each other.

**Which pings were successful?**

Pings between the configured PCs using IP addresses 192.168.1.10 to 192.168.1.14 were successful.

**Which ones failed and why?**

The ping to 192.168.1.15 failed because this IP address was not assigned to any device on the network, so no device could reply.
