## 🧠 5. Reflection Questions

### 5.1 What would happen if two PCs had the same IP address?

Two PCs using the same IP address would cause an IP address conflict, making communication unreliable. When I tried assigning PC0’s IP address to PC1, Packet Tracer displayed “address is already in use”.

### 5.2 Why do we use a switch instead of directly connecting PCs together?

We use a switch to connect multiple PCs so they can communicate on the same local network. Each PC has its own connection to the switch, so if one PC disconnects, the others can still communicate.

### 5.3 What does the subnet mask 255.255.255.0 indicate?

The subnet mask 255.255.255.0 indicates that the first three parts of the IP address identify the network, while the last part identifies the device.
