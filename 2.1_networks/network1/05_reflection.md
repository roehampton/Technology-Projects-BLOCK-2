## 🧠 5. Reflection Questions

### 5.1 What would happen if two PCs had the same IP address?
If two PCs have the same IP address on the same network, an IP address conflict occurs. This can cause network communication problems because the network cannot correctly identify which computer should receive the data. As a result, one or both PCs may experience connectivity issues and fail to communicate properly.

### 5.2 Why do we use a switch instead of directly connecting PCs together?
A switch is used to connect multiple computers within a local area network (LAN). It allows PCs to communicate with each other efficiently and provides a central connection point for the network. A switch also makes it easier to expand the network by adding more computers and devices. Without a switch, connecting multiple PCs would require more complicated connections.

### 5.3 What does the subnet mask 255.255.255.0 indicate?
The subnet mask 255.255.255.0 indicates that the first three octets (24 bits) represent the network portion of the IP address, while the last octet (8 bits) represents the host portion. This means that devices with the same network address, such as 192.168.1.10 and 192.168.1.11, can communicate within the same local network. It allows up to 254 usable host addresses in a standard IPv4 subnet.
