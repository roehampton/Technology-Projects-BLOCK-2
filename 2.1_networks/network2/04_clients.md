
## 💻 4. PC Configuration (DHCP Clients)

### 4.1 Explanation  
Describe how you configured PCs to obtain addresses automatically.
I configured the PCs to obtain IP addresses automatically using DHCP (Dynamic Host Configuration Protocol). First, I opened each PC in Cisco Packet Tracer and selected the Desktop tab. Then, I opened IP Configuration and selected the DHCP option instead of Static.

The PCs automatically received their IP addresses, subnet masks and other network settings from the DHCP server. This allowed all PCs to communicate on the network without manually entering IP addresses.
