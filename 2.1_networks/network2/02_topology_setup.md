
## 🗺️ 2. Network Topology Setup

### 2.1 Description  
Explain how you built the network topology (devices, cabling, layout).
I created the network topology using Cisco Packet Tracer. The network consists of five computers (PC0, PC1, PC2, PC3, and PC4) connected to a central switch (Switch0). I used Copper Straight-Through cables to connect each PC to the switch. This configuration forms a star topology, where the switch acts as the central communication device. Each PC was assigned a unique IP address within the same network range (192.168.1.0/24). The devices were arranged clearly in Packet Tracer to make the network easy to understand and manage. After completing the connections and IP configuration, I tested the network connectivity using the ping command.
