1. What are the advantages of DHCP over static IP assignment?
   
 DHCP has several advantages over static IP assignment:
 Automatic Configuration: DHCP automatically assigns IP addresses to devices without requiring manual configuration.
 Saves Time: It reduces the time needed to configure each computer individually.
 Prevents IP Conflicts: DHCP helps prevent two devices from receiving the same IP address.
 Easy Management: Network administrators can manage IP addresses from one DHCP server.
 Flexibility: Devices can connect and disconnect from the network and receive available IP addresses automatically.
Conclusion:DHCP is easier and faster to manage than static IP assignment, especially in large networks with many computers. It reduces manual work and helps avoid IP address configuration errors.

3. How does DNS improve usability in a network?
   
   DNS (Domain Name System) improves usability in a network by translating easy-to-remember hostnames into IP addresses. Users do not need to remember long numerical IP addresses to communicate with other computers or access websites.

For example, instead of remembering an IP address such as 192.168.2.100, users can use a hostname such as library_pc1.
Advantages of DNS:
 Makes network access easier.
 Saves users from remembering IP addresses.
 Allows computers to communicate using hostnames.
 Makes network management simpler.
 Reduces errors when accessing network devices.
Conclusion: DNS makes a network more user-friendly, convenient and easier to manage by allowing users to use names instead of numerical IP addresses.

5. What would happen if the DHCP server went offline?
   
If the DHCP server goes offline, new devices will not be able to receive IP addresses automatically. This may prevent them from connecting to the network properly.
Devices that already have an IP address may continue communicating using their existing DHCP lease until it expires. However, they may experience network connection problems when they need to renew their IP addresses.

Conclusion: If the DHCP server goes offline, network connectivity may be affected, especially for new devices. Therefore, the DHCP server is important for managing and automatically assigning IP addresses across the network.
