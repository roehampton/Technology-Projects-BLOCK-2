
## 📘 1. Objective (In Your Own Words)
Briefly describe the purpose of this lab.  
What were you trying to achieve?
The purpose of this lab was to configure IP addresses on computers and establish network connectivity using Cisco Packet Tracer. I was trying to achieve a better understanding of how computer networks work by using Cisco Packet Tracer. The main goal was to create a simple network, connect computers, assign appropriate IP addresses and subnet masks, and configure the network correctly. I also aimed to test network connectivity between devices using the ping command and verify that computers could communicate successfully. Through this lab, I wanted to improve my practical knowledge of IP addressing, network configuration, and basic troubleshooting.
